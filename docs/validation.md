# Development and validation checklist

- [ ] Verify the stock OpenSim gait workflow on the team's machines.
- [ ] Fit suspension stiffness and damping from a bench trial. Validate predicted travel and force on a different input or payload.
- [ ] Compare the locked and moving suspension with the same payload. Record pack fit, speed, suspension setting, and belt setting.
- [ ] Verify time alignment, SI units, and axis signs on one trial. Plot forces and application points in OpenSim to catch mapping errors.
- [ ] Check dynamic residual forces and moments before interpreting inverse dynamics. Document any missing or estimated interface loads and test sensitivity to those estimates.
- [ ] Compare paired trial waveforms and peaks for shoulder strap force, lumbar flexion moment, and knee extension moment. Preserve processing settings alongside results.
